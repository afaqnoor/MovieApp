# Project Name (MovieApp)

A brief description of what this project does and the problem it solves. 

## 🚀 Technologies Used
* **Frontend:** React, Next.js,
* * **API:** TMDB,
* **Styling:** Tailwind CSS, Material UI

## ✨ Key Features
* Intelligent TMDB API Integration:
  Leverages the TMDB API to fetch real-time, comprehensive data including trending movies, popular TV shows, and detailed metadata, ensuring content          accuracy.
* Categorized Content Discovery:
  Features a sophisticated UI layout that distinctly separates movies and TV shows, allowing users to navigate and filter their preferred content type with   ease.
* Immersive Detail & Engagement:
  Provides a dedicated detail page for every title, offering in-depth insights such as plot summaries, release dates, ratings, and cast information upon      user interaction.
* Integrated Trailer Streaming:
  Equipped with a seamless trailer playback feature, allowing users to preview movies and TV shows directly within the application to boost user              engagement.  

## 🛠️ How to Run Locally
1. Clone this repository: `git clone <url>`
2. Install dependencies: `npm install`
3. Run the project: `npm run dev`
